  Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0

- Universal Animation Library, Standard v3.0 — Quaternius / Gonzalo Furnier. CC0 1.0.
  Source: https://quaternius.itch.io/universal-animation-library
  Files: Assets/RPG/Art/UniversalAnimations. Original License.txt retained.

Only free files were downloaded. Existing Brute and Abe assets remain in place.

BruteNative contains copies of the user's existing Brute assets, imported as Generic
with the matching skeleton. These preserve authored foot rotations without Humanoid
retargeting. Player locomotion uses matching native Brute clips. The player hit,
death and airborne animations are baked from the Quaternius library onto Brute's
native bones; the CC0 source license is retained in UniversalAnimations/License.txt.

## Greenhollow and mounts (2026-10-29)

- LowPoly Animated Animals / Farm Animals Animated by Quaternius — CC0 1.0 Universal.
  Author's source: https://quaternius.itch.io/lowpoly-animated-animals

## Terrain / presentation

Assets/RPG/Terrain contains native TerrainData, terrain layers, conformed road meshes and seamless diffuse/normal textures generated by TerrainPolishSetup.cs. These procedural textures are created by project code. Village paving reuses the existing supplied brick textures; existing model/animation licenses above remain unchanged.
