# Western cargo props

The supply crate, grain sack and shared palette come from the Avramania Asset Library Free Collection. See [License.txt](License.txt) for the original CC0 notice. The selected files and their original Unity metadata came from the [teammate's pinned Unity import](https://github.com/hrisipisibg/riftbound-game/tree/3be646ebb05cbbbd0d03e6bdb54c400c8056abae/Assets/RPG/ThirdParty/CC0World/Medieval). The URP palette material comes from the same commit's CC0WorldArt folder.

The meshes are used on the western road quest cargo sites. The existing boxes handle collision and interaction.
