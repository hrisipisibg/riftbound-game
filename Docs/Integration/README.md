# Session validation runner

Verify-CombinedRelay.ps1 runs bounded same-machine session scenarios against a supplied standalone. Use its parameters to select the exact candidate and unique evidence directory. Keep authentication profiles isolated and redact invite codes/tokens from shared results.

Do not infer visual quality from headless success, or cross-network acceptance from two local processes. Report scenarios actually run and keep failures, skips and superseded builds distinct. Existing candidate directories are not replaced as part of a new test.
